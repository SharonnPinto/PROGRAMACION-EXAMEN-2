# PROGRAMACION-EXAMEN-2
SE CREO UN SISTEMA DE GESTION PARA UNA FARMACIA CON JAVA, HICE EL EXAMEN ANTES DE ABRIR EL EXAMEN EN CANVAS PORQUE PENSÉ QUE SI ME SALÍA DE LA APP SE ME CERRARÍA Y LUEGO ME DI CUENTA DE QUE ME HACÍAN FALTA COSAS PERO YA NO ME DARÍA TIEMPO.
SE UTILIZARON 2 CLASES Y UNA CLASE MAIN PARA EJECUTAR EL PROGRAMA.
SE USARON ATRIBUTOS PRIBADOES, UTILIZAMOS MÉTODOS PÚBLICOS PARA ACCEDER Y MODIFICAR CADA UNO DE LOS ATRIBUTOS.
SE UTILIZÓ LA CLASE INVENTARIO LA CUAL GESTIONA UNA LISTA DE OBJETOS DE TIPO PRODUCTO.
EN EL SISTEMA SE PUEDE AGREGAR PRODUCTOS, BUSCAR PRODUCTOS, CONSULTAR STOCK, VENDER, ACTUALIZAR PRECIOS, LISTAR PRODUCTOS.
